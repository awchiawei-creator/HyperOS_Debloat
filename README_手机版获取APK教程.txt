====================================================================
  小米 HyperOS 去广告精简助手（手机版 APK）- 2分钟免软件云打包教程
====================================================================

本压缩包内含完整的 Android 手机 App 源码，以及 GitHub 云端自动编译配置。
你无需在电脑安装庞大的 Android Studio，只需利用免费 GitHub 账号即可在 2 分钟内直接下载安装到小米手机的 .apk 文件：

【第一步：在 GitHub 云端一键生成 APK】
1. 解压本压缩包到电脑桌面。
2. 打开浏览器登录 GitHub (https://github.com)，点击右上角【+】->【New repository】新建一个仓库（名字随便填，例如 miui-debloat）。
3. 在新建仓库页面点击【uploading an existing file】，把解压出来的所有文件和文件夹（包括隐藏的 .github 文件夹！）全部拖进去，点击下方绿色按钮【Commit changes】。
4. 点击仓库顶部的【Actions】标签页，你会看到一个正在自动运行的编译任务（Build HyperOS Debloat APK）。
5. 等待约 1~2 分钟变成绿色对勾后，点进去在最下方【Artifacts】区域点击下载【小米HyperOS去广告精简助手-手机版APK】，解压后把 app-debug.apk 发到小米手机安装即可！

【第二步：在小米手机上无电脑激活权限】
1. 手机浏览器搜索下载并安装开源免费的「Shizuku」App。
2. 打开手机【设置】->【我的设备】->【全部参数与信息】，连续点击【OS版本】7次开启开发者模式。
3. 进入【设置】->【更多设置】->【开发者选项】，开启【USB调试】、【无线调试】以及【USB调试(安全设置)】。
4. 打开 Shizuku App -> 点击【配对】-> 点开通知栏输入【无线调试】里的 6 位配对码 -> 返回 Shizuku 点击【启动】。
5. 打开你刚安装的「小米去广告精简助手」App，点击授权后即可直接在手机上一键勾选精简、导入 .md 指南、拦截第三方 App 摇一摇广告！
